# Rajesh Kumar Dash — Portfolio

Personal portfolio site — built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds the site and publishes it to GitHub Pages.

To enable it on a fresh repo: **Settings → Pages → Source: GitHub Actions**.

Live at `https://rajesh2015.github.io/portfolio/`.
